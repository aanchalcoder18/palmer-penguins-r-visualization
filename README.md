# 🐧 Palmer Penguins Visualization in R

This project explores the **Palmer Penguins** dataset using R and **ggplot2**.  
It demonstrates the progression from simple scatter plots to advanced visualizations with color, faceting, and annotations.

---

## 🎯 Project Overview

The goal of this project is to showcase my data visualization skills in R by:
- Creating clear, informative plots with **ggplot2**
- Demonstrating step-by-step progression in plot design
- Using color, labels, and annotations for effective data storytelling

---

## 🧰 Tools and Libraries
- **R**
- **ggplot2**
- **tidyverse**
- **palmerpenguins**

---

## 📊 Key Visuals

The final visualization highlights the relationship between **flipper length** and **body mass** across penguin species, with annotations to emphasize insights.
